Gragarda Voice — free open-source OBS plugin for a pro voice

An OBS plugin that adds AI noise suppression and a full pro voice-studio chain to your microphone, in a single filter set up in 20 seconds by a calibration wizard. Made for streaming (Twitch, YouTube), podcasts and voice-over. Free and open source (GPL), OBS Studio 32+. Available for Windows 10/11, Linux and macOS coming soon.

Download   Source code · Support on Ko-fi

Features

  • AI noise suppression: DeepFilterNet 3 (Max quality, 51.5 ms) or RNNoise (Fast, 31.5 ms). Fixed, displayed latency.
  • Full chain: high-pass, corrective EQ, compressor, de-esser, tone EQ, leveler (LUFS target), look-ahead limiter.
  • 4 macros (Cleanup, Warmth, Clarity, Punch) + destination (Stream −14, Podcast −16, Voice-over −18 LUFS).
  • Calibration wizard: 5 s of silence + 15 s of reading → gain, automatic mic correction, 4 indicators.
  • Presets per mic, switchable live from Streamer.bot / Stream Deck.
  • Before/After at matched loudness, auto-sync of cameras, duplicate filter detection.
  • Interface in 34 languages.

Install

  1. Download gragarda-voice-<version>-setup.exe from the releases.
  2. Close OBS and run the installer.
  3. In OBS: right-click your mic → Filters → + → Gragarda Voice → Run calibration.
  4. Set your camera's Render Delay to the displayed latency, or click Auto-sync.

Most of the code was written by an AI (Claude, by Anthropic) under the author's direction, and tested by ear in OBS on several microphones.

Gragarda Voice — plugin OBS gratuit et open source pour une voix pro

Un plugin OBS qui ajoute à votre micro une suppression de bruit par IA et toute la chaîne d'un studio voix pro, en un seul filtre réglé en 20 secondes par un assistant de calibration. Pour le streaming (Twitch, YouTube), le podcast et la voix-off. Gratuit et open source (GPL), OBS Studio 32+. Disponible pour Windows 10/11, Linux et macOS bientôt.

Fonctionnalités

  • Suppression de bruit par IA : DeepFilterNet 3 (Qualité max, 51,5 ms) ou RNNoise (Rapide, 31,5 ms). Latence fixe et affichée.
  • Chaîne complète : passe-haut, EQ correctif, compresseur, de-esser, EQ de couleur, leveler (cible LUFS), limiteur à anticipation.
  • 4 macros (Nettoyage, Chaleur, Clarté, Punch) + destination (Stream −14, Podcast −16, Voix-off −18 LUFS).
  • Assistant de calibration : 5 s de silence + 15 s de lecture → gain, correction automatique du micro, 4 voyants.
  • Presets par micro, changeables en direct depuis Streamer.bot / Stream Deck.
  • Avant/Après à volume compensé, synchronisation automatique des caméras, détection des filtres en double.
  • Interface en 34 langues.

Installation

  1. Télécharger gragarda-voice-<version>-setup.exe dans les releases.
  2. Fermer OBS et lancer l'installeur.
  3. Dans OBS : clic droit sur le micro → Filtres → + → Gragarda Voice → Lancer la calibration.
  4. Régler le Retard de rendu de la caméra sur la latence affichée, ou cliquer sur Synchroniser automatiquement.

L'essentiel du code a été écrit par une IA (Claude, d'Anthropic) sous la direction de l'auteur, et testé à l'écoute dans OBS sur plusieurs micros.
